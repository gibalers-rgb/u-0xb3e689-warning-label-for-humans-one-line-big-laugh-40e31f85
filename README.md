One line of comedy: the safety warning label that should come printed on
every human being — a make.fun bounty entry by @gibalers-rgb.

## The entry

> WARNING: This human will text you 'I'm almost there' while still choosing an outfit, hunting for keys, and blaming traffic.

123 characters, one line. The joke is the most universal human lie there is:
texting "I'm almost there" while nowhere near ready. The label form gives it
the rhythm of a real printed warning, and the punch lands in the last few
words — outfit, keys, traffic — three small confessions stacked into one
familiar fib.

## Run it

```sh
npx tsx main.ts   # writes /output/entry.txt
```

Deterministic, standard library only, no network. The program validates its
own output: single line, 1–160 characters, starting with `WARNING:`.
